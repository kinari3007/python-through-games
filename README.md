## ▶️ How to Run a Game

### 1. Clone the repository

```bash
git clone https://github.com/kinari3007/python-through-games.git
```

### 2. Open the project folder

```bash
cd python-through-games
```

### 3. Run the game script

```bash
python "Level-1-Beginner-Arcade\Rock-paper_scissors.py"
```

If you want to run another file, replace the filename with the desired script.
