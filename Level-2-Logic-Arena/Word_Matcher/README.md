# Word Matcher

A beginner-friendly Python mini project that searches for a word inside a sentence and counts how many times it appears.

---

## Features

- Search for a word in a sentence
- Count word frequency
- Show positions of matched words
- Case-insensitive matching

---

## Concepts Practiced

- Variables
- User Input
- Strings
- String Methods
- Loops
- Conditions
- Lists
- Basic Debugging
